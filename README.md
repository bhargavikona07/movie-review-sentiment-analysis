# MOVIE REVIEW SENTIMENT ANALYSIS

## PROJECT OVERVIEW
This project analyzes movie reviews and determines whether the sentiment is Positive or Negative using Python. The system processes review text, identifies positive and negative words, and classifies the overall sentiment.

## TECHNOLOGIES USED
- Python
- Pandas
- Jupyter Notebook

## DATASET
The project uses the IMDb Movie Reviews Dataset, which contains movie reviews and their corresponding sentiment labels.

## STEPS PERFORMED
- Loaded the IMDb dataset
- Processed movie review text
- Identified positive and negative words
- Calculated sentiment scores
- Classified reviews as Positive or Negative
- Displayed sentiment prediction results

## RESULT
The system predicts whether a movie review is:
- POSITIVE
- NEGATIVE

## KEY FEATURES
- Text-based sentiment analysis
- Review classification using Python
- Simple and easy-to-understand implementation
